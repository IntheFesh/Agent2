## 1. 文件与条目数

数据集卡 "Dataset Files" 一节的原文摘录：

> | `gen_scenario.jsonl` | 1,000 | Synthesized scenario descriptions |
> | `gen_tasks.jsonl` | 1,000 | 10 user tasks per scenario |
> | `gen_verifier.jsonl` | 10K | Verification code for code-augmented LLM-as-a-Judge |
> | `gen_verifier.pure_code.jsonl` | 10K | Verification code for purely code-based Judge |

实测（`wc -l` 与逐行 JSON 解析）：

| 文件 | 数据集卡 | 实测行数 | 说明 |
|---|---|---|---|
| `gen_scenario.jsonl` | 1,000 | 1000 | 字段 `name`、`description`；场景名无重复 |
| `gen_tasks.jsonl` | 1,000 | 1000 | 每条恰好 10 个任务，合计 10000 个任务 |
| `gen_db.jsonl` | 1,000 | 1000 | |
| `gen_sample.jsonl` | 1,000 | 1000 | |
| `gen_spec.jsonl` | 1,000 | 1000 | |
| `gen_envs.jsonl` | 1,000 | 1000 | |
| `gen_verifier.jsonl` | 10K | 10476 | 覆盖全部 10000 个 (scenario, task_idx)；其中 476 行是重复键 |
| `gen_verifier.pure_code.jsonl` | 10K | 10010 | 覆盖全部 10000 个 (scenario, task_idx)；其中 10 行是重复键 |

结论：8 个文件齐全，条目数与数据集卡一致（verifier 文件的 "10K" 是约数，多出的行都是重复键）。AWM 在按键查找 verifier 时取第一条匹配（`third_party/agent-world-model/awm/tools.py:456-472`，`find_scenario_entry`；调用处 `awm/core/verify.py:383-384`），因此重复行不影响运行。本仓库不修改官方文件（R2）。

各文件的 sha256 与 HF tree 接口列出的 LFS oid 一致（见日志），测试前后未变。

## 3. 在官方环境上观察到的返回形态

在隔离的会话数据库副本上调用：

| 调用 | 返回 | 对本仓库的影响 |
|---|---|---|
| `search_products {"query": "no-such-product-zzz"}` | `isError=False`，`{"products": [], "total": 0}` | 原网关规则只认 `[]`，会误判为 `ok`；已修正（ADR-014） |
| `get_product_by_id {"product_id": "abc"}` | `isError=True`，`Input validation error: 'abc' is not of type 'integer'` | 新的错误形态；已补充 `expected_type`（ADR-014） |
| `add_item_to_cart {"quantity": 1}` | `isError=True`，`… 'product_offer_id' is a required property` | 与已知形态一致 |
| `get_product_by_id {"product_id": 999999}` | `isError=False`，返回 `id: 0` 的占位对象 | 上游生成代码的行为；网关无法通用识别（LIMITATIONS） |
| `remove_cart_item` / `delete_user_payment_method`（不存在的 ID） | `isError=False`，`{"success": false}` | 判为 `ok`，由模型读取 `success` 字段 |
| `add_item_to_cart {"product_offer_id": 999999, "quantity": 1}` | `isError=False`，写入一条引用不存在 offer 的购物车行 | 上游不校验外键；只能靠审批与 DB diff 暴露（LIMITATIONS） |
