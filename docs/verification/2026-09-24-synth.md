- **没有 embedding 端点**：`gen scenario` 用断言强制要求 `EMBEDDING_OPENAI_API_KEY`（`awm/core/scenario.py:63`），而 DeepSeek 没有 embedding 接口：
  - 2026-09-24 20:43 UTC 查阅，文档站点地图的 9 个 API 页面中没有 embeddings；

- **上游 CLI 支持从 `gen task` 开始**：`awm gen task --input` 是 "scenario description file"（`awm/core/task.py:13`，CLI 帮助中为必填），每条只用 `name` 与 `description`（`:44-45`）。所以按 D5 跳过场景生成。

  - 名称必须以 `local_` 开头、不以 `_<数字>` 结尾；官方数据在本地时，还要与官方场景名逐一比对。
  - 只靠前缀不够：官方场景名中有 `local_search_1` 与 `local_services_marketplace_1`。
- **手写场景**（D5：企业类，名称加 `local_` 前缀，格式与官方 `gen_scenario.jsonl` 一致）：`data/synth/p13_it_service_desk/local_scenario.jsonl`，全文见日志开头。

## 4. 仍然存在的限制

- `gen scenario` 没有执行过：本轮没有 embedding 端点。U9 中这一部分仍未验证。
- 只合成了 1 个场景、10 个任务；AWM 的整步重试、错误摘要请求都没有被触发，因此没有验证。
